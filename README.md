### How to use

1. Launch the program  
2. Paste your YouTube video link  
3. Select a profile (Safe recommended)  
4. Set desired views amount  
5. Click **Start**

---

### Configuration

All settings are stored in `config/default.json` and profile files:

- Delivery speed  
- Watch time percentage  
- Engagement rate  
- Proxy list  
- Daily limits  
- Safety delays
